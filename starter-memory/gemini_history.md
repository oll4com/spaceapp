# SpaceApp Memory

## Welcome

- This memory belongs to your clean SpaceApp installation.
- Add durable project notes through SpaceApp when you want agents to remember them.
- Provider credentials, session secrets, browser profiles, and backup encryption keys do not belong here.

## First steps

- Claim the first owner account from the setup screen.
- Connect only the CLI providers you intend to use.
- Create a test room and verify one provider at a time.
- Create a portable backup before upgrades or major configuration changes.

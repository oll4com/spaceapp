# Welcome to SpaceApp

This is the immutable starter memory shipped with the public alpha. Add your
own notes through SpaceApp; mutable owner memory is stored separately and is
never included in images or source releases.

Useful first steps:

1. register only the host workspaces you want SpaceApp to access;
2. connect each provider through its official login flow or masked credential
   input;
3. create a test room and verify one CLI at a time;
4. make a backup before upgrading.

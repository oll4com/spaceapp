# Evidence contract

`TERMINAL_RENDER` is an addition to Space Control, not a new top-level Space Ops tool. `visual_audit` is a bounded single-pane action. Full/readonly catalogs stay seven/three. `PROVE_CLI_RENDER` is excluded from readonly.

Availability (FRESH/STALE/UNAVAILABLE/UNSUPPORTED) is separate from verdict (HEALTHY/SUSPECTED/FAULT/INCONCLUSIVE/NOT_APPLICABLE). HEALTHY means measured geometry; stream counters remain null when unavailable. Browser surface generation is not a native CLI session identity. Server session changes during an audit invalidate the result.

Clipping must exceed cell/rounding tolerance and persist on the same stable surface in a second sample. A generic 0.96 coverage threshold is invalid. Padding, cell rounding, DPR and scrollbars are accounted for. No text, transcript, keyboard/clipboard data or operator-content hashes are exported.

Synthetic fixture tokens are precisely counted with Unicode lexical tokenizer version 1 (`[\p{L}\p{N}]+|[^\s\p{L}\p{N}]`). These counts are reproducible load units only, not billed/provider tokens. Markers and SHA256 are for known public fixture content only. A complete transport digest and expected final DOM screen are distinct evidence levels; screenshots require native visual review. The fixed runtime allowlist is Codex, Gemini and OpenCode. The `ALL` selection uses those three panes in one owned room and never launches a provider CLI or consumes provider quota.

Profiles record requested/actual geometry and backend PTY dimensions. Unsupported UI dimensions remain UNSUPPORTED. Resizes are induced on the owned terminal container, never by directly calling host.resize. The production resize/PREFILL/output code is unchanged.

Joint live acceptance still includes light/dark, DPR/zoom, image paste and the protected room-switch baseline: warm p95 <=250 ms, cold <=900 ms, same sessions/xterms/sockets after >=35 seconds hidden. Use identical A/B fixtures and timing instrumentation. Repeated regression >max(5%,10 ms) blocks rollout. Retain old raw resize-failure counts; A->B->A and force are not consecutive duplicate resizes.

A real AI task requires native submit, response/completion and trustworthy input/output/reasoning usage. Without verified >=50k output tokens its result remains INCOMPLETE. Do not equate starting a CLI with executing a task or use synthetic tokens as AI usage.

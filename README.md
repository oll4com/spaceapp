## 🌟 What is SpaceApp?

SpaceApp is a web app you run on your own machine with Docker. It replaces a wall of terminal windows with **rooms**: each room holds **panes**, and each pane is an AI coding CLI, a copilot, a browser or a tool.

<p align="center">
  Run <b>OpenCode</b>, <b>OpenAI Codex</b>, <b>Claude Code</b>, <b>Google Gemini</b>, <b>Qwen</b>, <b>Kimi</b>, <b>Grok</b>, and <b>DeepSeek</b> concurrently in persistent rooms on your own machine. Rooms organize sessions; they are not a security boundary between mutually untrusted users.

## ⚡ Quick start

One command on Linux, macOS or Windows 11. Docker is installed automatically if it is missing:

```bash
npx --yes run-spaceapp@latest install
```

1. The launcher checks CPU, RAM and disk, and installs or starts Docker.
2. It checks the SBOM and provenance attestations of SpaceApp's images, pulls them by the digest the npm package pins and starts the stack.
3. It prints a 15-minute setup token and opens `http://127.0.0.1:4911`.
4. You paste the token and create your owner account.
5. The Getting Started room opens with **OpenCode**: check its model, sign in if it asks, and give it a small task.

> **Windows:** use Command Prompt (`cmd.exe`). If PowerShell blocks scripts, run `npx.cmd --yes run-spaceapp@latest install`.

Copilots and studios are optional modules: turn one on with `optionalModules` in the launcher's `config.json`, then run `repair`. What a self-hosted install cannot do yet is in the [Known Limitations](docs/quality/KNOWN_LIMITATIONS.md).

## 🧠 Nous

Nous is SpaceApp's own agent. It reads every pane's progress, sends the next steps and works on your goals (`/goal <what you want>` in its composer) in turns of its own until they are done. It asks you before releases, deletes, anything to third parties or money, and changes of direction; the allowances that let it do more alone are off until you turn them on.

From `run-spaceapp` 1.2.0 Nous runs on a self-hosted install too: each turn is a headless Claude Code run in `spaceapp-cli` on **your own Claude Code login**, with lean defaults. Connect Claude Code, then switch on **Work on my behalf** in the Nous dock. Goals, allowances, tools, the install path, a goal from start to finish and the limits of a self-hosted install: [Nous guide](docs/nous.md).

## 🏗️ Under the hood

A Docker Compose stack. The launcher picks the largest profile your machine fits, or you pass `--profile <name>`:

| Profile | Containers | Needs |
| :--- | :--- | :--- |
| `small` | `spaceapp-core` (web app and API) · `spaceapp-cli` (the AI CLIs) · `postgres` (data and pgvector memory) | 4 CPUs, 7 GiB RAM, 6.5 GiB disk |
| `medium` | small + `temporal` (background workflows) | 4 CPUs, 11 GiB RAM, 8 GiB disk |
| `large` | medium + `spaceapp-browser` (managed Chrome) | 8 CPUs, 15 GiB RAM, 11 GiB disk |

- **Your files:** the containers see none of your host files until you register a folder with `workspace add <path>` (`--read-only` for reference repos). Containers are not a sandbox against a hostile workload; read the [trust boundaries](docs/architecture.md#trust-boundaries).
- **The code:** a TypeScript monorepo: `apps/web` (React), `apps/api` (Fastify), `apps/worker` (Temporal) and shared `packages/` (contracts, db, runtime, gateway, run-spaceapp launcher, …). Development requires Node **>=26.13 <27**; see [Contributing](CONTRIBUTING.md).

## 💻 Everyday commands

Run `npx --yes run-spaceapp@latest <command>`, or `spaceapp <command>` after `npm install -g run-spaceapp`:

| Command | What it does |
| :--- | :--- |
| `up` · `down` · `status` · `logs` | Start, stop and check the stack |
| `update` · `rollback` | Update the images, or go back to the previous ones (database changes stay; use `restore` for those) |
| `backup` · `restore` | A checksummed archive of the database, settings and memory |
| `workspace add <path>` | Let agents work in one of your folders |
| `provider install <name>` | Add an AI coding CLI (`codex`, `claude`, `gemini`, `qwen`, …) |
| `credentials set <provider>` | Save an API key through masked input |
| `doctor --fix` | Find and repair install problems |
| `owner reset-password` · `owner rotate-setup-token` | Forgotten password, or an expired setup token |

Every command and option: [Operations guide](https://github.com/oll4com/spaceapp/blob/main/docs/operations.md).

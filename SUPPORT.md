# Support

SpaceApp is a community-maintained self-hosted project. Public support is
best-effort and has no response-time guarantee.

## Installation and usage

Search existing GitHub issues before opening a new one. Use the bug report form
for reproducible failures and include:

- SpaceApp and `run-spaceapp` versions;
- operating system and CPU architecture;
- Docker Engine/Desktop and Compose versions;
- selected `light` or `standard` profile;
- minimal reproduction steps and sanitized error output.

Public reports must never include credentials, setup tokens, cookies, personal
memory, private workspace content, customer data, internal hostnames, or
private network addresses.

## Security vulnerabilities

Do not report a suspected vulnerability in a public issue. Use GitHub's private
security advisory form:

https://github.com/oll4com/spaceapp/security/advisories/new

Read [SECURITY.md](SECURITY.md) for the supported version and disclosure
process.

## Provider accounts

SpaceApp does not provide provider accounts, API credits, billing support, or
provider-specific service guarantees. Authentication and usage remain subject
to each provider's terms and support channels.
